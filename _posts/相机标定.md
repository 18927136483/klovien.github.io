# 相机模型与标定

## 学习网址

[最详细、最完整的相机标定讲解-CSDN博客](https://blog.csdn.net/a083614/article/details/78579163)

### 基础知识

含义：求解参数（内参、外参、畸变参数）的过程

畸变(distortion)：对直线投影（rectilinear projection）的一种偏移。

光学畸变（optical aberration）：一条直线投影到图片上不能保持为一条直线

**相机的畸变和内参是相机本身的固有特性，标定一次即可一直使用。**

- **图像坐标系**：通常以图像的中心为原点（在某些情况下，也可能是图像的左上角等，取决于定义），x轴和y轴方向与图像的行和列方向平行。图像坐标系中的坐标值单位通常是物理长度单位，如毫米（mm）等，用于描述图像中物体的实际位置。
- **像素坐标系**：以图像的左上角为原点，x轴向右为正方向，y轴向下为正方向。像素坐标系中的坐标值单位是像素（pixel），用于表示像素在图像中的位置。

**dx和dy的含义**

- **物理意义**：dx和dy是在图像坐标系和像素坐标系转换过程中涉及的参数，它们表示每个像素在方向和方向上对应的物理尺寸。
- dx是指在x方向上，每个像素所代表的物理长度。例如，如果dx=0.1mm/pixel，这意味着在图像坐标系中，x方向上每一个像素的宽度对应实际物理世界中的0.1mm。
- dy是指在y方向上，每个像素所代表的物理长度。同理，若dy=0.1mm/pixel，y方向上每一个像素的高度对应实际物理世界中的.1mm。

### 畸变

主要分类：径向畸变、切向畸变

> 畸变是相机本身的固有特性，和相机内参相同，标定一次之后即可。
>
> 径向畸变来自于透镜形状。
>
> 切向畸变来自于整个摄像机的组装过程。

![image-20250107152903365](C:\Users\86189\AppData\Roaming\Typora\typora-user-images\image-20250107152903365.png)

#### 一、**径向畸变（桶形畸变和枕形畸变）**

> 实际摄像机的透镜总是在成像仪的边缘产生显著的畸变，这种现象来源于“筒形”或“鱼眼”的影响。

### 标定方法

#### 1、传统相机标定

最简单的相机标定为线性标定，即不考虑相机的畸变而只考虑空间坐标转换。

每个坐标点有X,Y两个变量，可列出两个方程，相机内参有5个未知数，外参平移和旋转各3个，共有11个变量，因此至少需要6个特征点来求解。

#### 2、非线性标定

当镜头畸变明显时必须考虑畸变，一般较为便宜的网路摄像头畸变特别大，而价格较贵的工业摄像头则畸变很小，因为其中已经嵌入了许多消除畸变的程序。这时线性模型转化为非线性模型，需要通过非线性标定方法求解。有最速下降法、遗传算法、高斯牛顿法和神经网络算法等。

#### 3、张正友标定介绍

> 张正友标定只考虑了径向畸变，没有考虑切向畸变

### 标定过程

#### **相机标定步骤：**

> 1. 打印一张棋盘格A4纸张（黑白间距已知），把它贴在一个平面上，作为标定物。
> 2. 通过调整标定物或摄像机的方向，为标定物拍摄若干张不同方向的照片（一般10-20张）。
> 3. 从照片中提取棋盘格角点（检测特征点（Harris特征））
> 4. 利用解析法估算方法，计算出理想无畸变的情况下的五个内参和六个外参。
> 5. 应用最小二乘法估算实际存在径向畸变下的畸变系数。
> 6. 根据极大似然法，设计优化估计目标，提升估计精度。

#### OpenCV标定

> 1. 循环读取图片
> 2. 使用findChessboardCorners()函数检测角点数（需提前输入角点数）。
> 3. 使用cornerSubpix()函数对角点进行精确检测。
> 4. 可用drawChessboardCorners()将角点显示。
> 5. 根据角点数和尺寸，创建一个理想的棋盘格（用point向量存储所有理论上的角点坐标）。
> 6. 通过calibrateCamera()函数由理想坐标和实际图像坐标进行标定，可得到标定结果。
> 7. 由projectPoints()函数计算反向投影误差。

##### 代码

```python
import cv2
import numpy as np
import glob

np.set_printoptions(suppress=True)

# 找棋盘格角点
# 阈值
criteria = (cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 30, 0.001)

#棋盘格模板规格
w = 6   #内角点数，内角点是和其他格子相连着的点
h = 4

# 世界坐标系中的棋盘格点,例如(0,0,0), (1,0,0), (2,0,0) ....,(8,5,0)，去掉Z坐标，记为二维矩阵
objp = np.zeros((w*h,3), np.float32)
objp[:,:2] = np.mgrid[0:w,0:h].T.reshape(-1,2)
#储存棋盘格角点的世界坐标和图像坐标对
objpoints = [] # 在世界坐标系中的三维点
imgpoints = [] # 在图像平面的二维点

images = glob.glob('Checkerboard/*.png')
i=0
for fname in images:
    img = cv2.imread(fname)
    gray = cv2.cvtColor(img,cv2.COLOR_BGR2GRAY)
    ret,corners = cv2.findChessboardCorners(gray,(w,h),None)
    #找到足够的点对，将其存储起来
    if ret == True:
        # 角点精确检测
        # 输入图像 角点初始坐标 搜索窗口为2*winsize+1 死区 求角点的迭代终止条件
        i+=1
        cv2.cornerSubPix(gray,corners,(11,11),(-1,-1),criteria)
        objpoints.append(objp)
        imgpoints.append(corners)
        #将角点在图像上显示
        cv2.drawChessboardCorners(img,(w,h),corners,ret)
        cv2.imshow('findCorners',img)
        cv2.imwrite('Corners/h'+str(i) +' .jpg', img)
        cv2.waitKey(100)
cv2.destroyAllWindows()

# 标定、去畸变
# 输入：世界坐标系里的位置 像素坐标 图像的像素尺寸大小 3*3矩阵，相机内参数矩阵 畸变矩阵
# 输出：标定结果 相机的内参数矩阵 畸变系数 旋转矩阵 平移向量
ret, mtx, dist, rvecs, tvecs = cv2.calibrateCamera(objpoints, imgpoints, gray.shape[::-1], None, None)
# mtx：内参数矩阵
# dist：畸变系数
# rvecs：旋转向量 （外参数）
# tvecs ：平移向量 （外参数）
print(("ret:"), ret)
print(("mtx:\n"), mtx)  # 内参数矩阵
print(("dist:\n"), dist)  # 畸变系数   distortion cofficients = (k_1,k_2,p_1,p_2,k_3)
print(("rvecs:\n"), rvecs)  # 旋转向量  # 外参数
print(("tvecs:\n"), tvecs)  # 平移向量  # 外参数

# 去畸变
img2 = cv2.imread('Corners/h1 .jpg')
h, w = img2.shape[:2]
# 我们已经得到了相机内参和畸变系数，在将图像去畸变之前，
# 我们还可以使用cv.getOptimalNewCameraMatrix()优化内参数和畸变系数，
# 通过设定自由自由比例因子alpha。当alpha设为0的时候，将会返回一个剪裁过的将去畸变后不想要的像素去掉的内参数和畸变系数；
# 当alpha设为1的时候，将会返回一个包含额外黑色像素点的内参数和畸变系数，并返回一个ROI用于将其剪裁掉
newcameramtx, roi = cv2.getOptimalNewCameraMatrix(mtx, dist, (w, h), 0, (w, h))  # 自由比例参数

dst = cv2.undistort(img2, mtx, dist, None, newcameramtx)
# 根据前面ROI区域裁剪图片
# x, y, w, h = roi
# dst = dst[y:y + h, x:x + w]
cv2.imwrite('Corners/calibresult.jpg', dst)

# 反投影误差

# 通过之前计算的内参数矩阵、畸变系数、旋转矩阵和平移向量，使用cv2.projectPoints()计算三维点到二维图像的投影，
# 然后计算反投影得到的点与图像上检测到的点的误差，最后计算一个对于所有标定图像的平均误差，这个值就是反投影误差。
total_error = 0
for i in range(len(objpoints)):
    imgpoints2, _ = cv2.projectPoints(objpoints[i], rvecs[i], tvecs[i], mtx, dist)
    error = cv2.norm(imgpoints[i], imgpoints2, cv2.NORM_L2) / len(imgpoints2)
    total_error += error
print(("total error: "), total_error / len(objpoints))
```

#### 对比分析

1. **焦距差异**：Matlab 和 OpenCV 中的焦距值（ f~x~ 和 f~y~ ）有明显差异。这可能是由于校准过程中的**单位**不同，或者是由于不同的算法和数据集导致的。通常，焦距值与图像分辨率和相机物理特性相关。

2. **主点差异**：Matlab 和 OpenCV 中的主点坐标（ u~0~和 v~0~）也有所不同。这可能是由于校准方法、图像坐标系的定义或者是数据处理的差异导致的。

3. **倾斜参数**：Matlab 中明确给出了倾斜参数 s  ，而 OpenCV 的内参矩阵形式中通常假设倾斜参数为 0。这意味着 OpenCV 的内参矩阵形式适用于大多数情况下相机镜头没有明显倾斜的场景。
